## Archived pattern examples

This folder holds code examples for patterns that appeared in earlier editions of Generative AI Design Patterns but are no longer part of the book. The code is kept here so that readers of earlier printings can still find and run it.

If you are following the current edition, you will not find these patterns in the book. Use the replacement listed below instead.

| Pattern Number | Archived Pattern | Archived Code | Replaced By |
| -------------: | :--------------- | :------------ | :---------- |
| 19 | Dependency Injection | [19_dependency_injection](19_dependency_injection) | Pattern 19: Harness Engineering, in [examples/19_harness_engineering](../19_harness_engineering) |

### Pattern 19: Dependency Injection

Newer editions of the book no longer carry Dependency Injection as Pattern 19. It has been replaced by Pattern 19: Harness Engineering, which covers how to give an agent a well-scaffolded environment to work in: a scoped workspace, a curated set of tools, and a test loop that gives the agent feedback on every iteration.

The Dependency Injection notebook still runs as written. See [19_dependency_injection](19_dependency_injection).
